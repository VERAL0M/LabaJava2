## О работе

В этой лабораторной я создал классы для работы с точками, линиями и студентами. Примеры запускаются через меню в классе `Main`.

## Выполненные задания

### 1.1. Точка

Класс `Point` хранит координаты `x` и `y`. Метод `toString()` выводит точку в формате `{x;y}`. В программе можно ввести координаты и создать три точки.

### 2.1. Прямая

Класс `Line` хранит точки начала и конца. В `Main` создаются три линии с координатами из задания. Третья линия использует точку начала первой линии и точку конца второй. Поэтому изменение этих объектов `Point` видно в третьей линии. Затем начало первой линии заменяется новым объектом: это не меняет начало третьей линии, потому что она продолжает ссылаться на прежнюю точку.

### 3.1. Студент

Класс `Student` хранит имя и массив оценок. В программе создаются Вася, Петя и Андрей. Сначала оценки Пети берутся из массива Васи, поэтому оба студента используют один массив: изменение оценки Пети отражается у Васи. Для Андрея создаётся отдельный массив оценок, поэтому изменение его оценки не меняет оценки Васи.

### 4.1. Точки

Создаются и выводятся точки `{3;5}`, `{25;6}` и `{7;8}`.

### 4.7. Студенты

Создаются Вася с оценками `3, 4, 5` и Максим без оценок. Для Максима выводится длина массива оценок.

### 5.6. Студент-отличник

Для Васи с оценками `3, 4, 5, 4` и Пети с оценками `5, 5, 5, 5` выводятся средний балл и результат проверки, является ли студент отличником.

## Запуск программы

Откройте проект в IntelliJ IDEA и запустите класс `Main`. В консоли выберите пункт от `1` до `5`. Для выхода введите `0`. При вводе координат программа проверяет, что введено целое число.

Дополнительные библиотеки не используются.
